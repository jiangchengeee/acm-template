# 算法竞赛模板库

个人 ACM/ICPC 模板库。`template.pdf` 是全部代码与推导笔记的合订本（164 页），由 `gen_tex.py` 自动生成。

## 编译 PDF

```bash
python3 gen_tex.py      # 扫描目录、生成 template.tex
xelatex template.tex
xelatex template.tex    # 目录需要跑两遍
```

新增模板：把 `.cpp` / `.tex` 放进对应文件夹，重新跑 `gen_tex.py` 就会自动收录（按文件名字典序排列）。

## 目录

| 目录 | 内容 |
|---|---|
| `stl库/` | 常用 STL 容器与坑（纯片段，无 `main`） |
| `数据结构/` | 树状数组、线段树、主席树（第 k 小 / 第 k 大 / 区间元素数 / 区间 MEX）、区间 mex、莫队、01-trie |
| `树论/` | 倍增求 LCA、启发式合并（dsu on tree）、树链剖分 |
| `图论/` | 最短路、欧拉路径、拓扑排序、MST、Tarjan 缩点、2-SAT、差分约束、二分图匹配、最大流、最小费用最大流 |
| `字符串/` | KMP、哈希、Manacher、AC 自动机 |
| `数学/` | 数论、exgcd、CRT、Lucas、欧拉筛、整除分块、线性基（贪心 / 前缀 / 方案还原与删除）、高斯消元、行列式、矩阵快速幂、组合数、莫比乌斯反演、三分、卷积（FFT / NTT / 任意模数 NTT）、线性求逆元 |
| `计算几何/` | 凸包、凸包面积、旋转卡壳、极角排序、闵可夫斯基和与皮克定理 |
| `博弈论/` | SG 函数 |
| `杂项/` | `__int128`、modint、CDQ 分治、CDQ 优化 DP、动态 DP |

带 `（推导笔记）` 后缀的 `.tex` 是配套的理论推导（CRT、Lucas、卷积、莫比乌斯反演、范德蒙德卷积、CDQ、动态 DP、网络流经典模型），会和代码一起编进 PDF。

## 使用约定

- 模板代码以 `#include <bits/stdc++.h>` + `#define int long long` + `up/down` 宏为基础风格，`启动文件.cpp` 是骨架；
- 多数 `.cpp` 自带 `main()` 与末尾的样例注释：前半是输入，紧跟的 `//` 行是**程序真实输出**；
- 26 个纯片段（stl 库全部、倍增、dsu、莫队、树状数组、线段树（区间max）、01-trie、exgcd、欧拉筛、线性求逆元、dij、欧拉路径、int128、modint、极角排序）没有 `main`，需要贴在 `启动文件.cpp` 后面；
- 需要 32 位的地方显式写 `int32_t`（01-trie、前缀线性基的数组），否则 `#define int long long` 会让内存翻倍。
